CV STUDIO / EXPERIMENT

Your sourcing assistant,
in the browser.

This separate POC uses your saved DeepSeek key. CV Studio can keep running as usual.

1. Load the extension once

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode, select Load unpacked, and choose this folder:{{ extension_path }}
  3. Pin CV Studio Sourcer POC from Chrome’s Extensions menu.

2. Connect this session

Open the extension and paste this pairing code into Connect:

{{ pair_code }}

This code connects only to the local bridge. It changes when the bridge restarts. Your DeepSeek API key is never sent to the extension.

3. Try one search

Sign into LinkedIn, Recruiter Lite or Recruiter. Open its search page, open the Sourcer side panel, enter your brief and choose a small page limit first. Start confirms the displayed DeepSeek data use and request limit.

Sample-page tests do not prove compatibility with every live LinkedIn layout. If a page is not recognized, the agent stops. LinkedIn restricts unauthorized automation; this POC does not bypass login checks, CAPTCHAs or usage limits. No messages, connections, profile edits or JobAdder writes are supported.
