# Job Leads and companion review corrections

Historical release evidence; root `VERSION` is the live release identity.

Source v24.6.452 on `codex/v24.6.452-review-corrections` starts from unmerged
v451 `c8c83af`. The owner authorized fixing all three independently reproduced

## Corrections

1. Changing an unsaved job's identity asks before replacing the draft's
   job-specific fields. Only a successful new read clears those fields; its
   folder remains. Cancellation/read failure restores the original URL and
   content. Same-job corrections remain. Manual field edits and rich paste bind
   the draft to its current URL, and Save independently rejects a mismatched
   source. Existing saved leads require New lead before switching jobs.
2. The companion retains binding/run authority, bounded observed URLs, counters
   and owned-tab identities in Chrome extension session memory. Recovery checks
   the original live app document ID and DOM marker before accepting commands.
   Browser/extension restart still requires reconnecting. Storage failures stop
   commands visibly. Same-document toolbar rearming cannot reset run limits.
   Session storage is extension-only by default and is not disk/sync persistence.
   No credentials, provider payloads, results or captured profile text are stored.
3. Profile navigation/read checks current ownership, activation, committed URL
   and pending URL. Activation/navigation events persist relinquishment, so a
   subsequently inactive user-taken-over tab is not overwritten or cleaned up.
   The read guard checks again after script injection. Temporary job tabs are
   also tracked for conservative cleanup after interruption.

The follow-up reviewer caught an overly strict first ownership guard: normal
navigation can report the old committed URL with the expected pending URL.
Two additional failing cases were added before correcting that guard. Inactive
loading navigation to the exact commanded target now keeps ownership and the
existing loading-poll contract, including fresh about:blank tabs and suspension
mid-navigation. Activated tabs or a different pending URL still fail closed.

The manifest adds only extension storage permission; existing host permissions
and four-file packaging remain. All 120 routes, five guards, schema-10 data,
Job Leads schema 1, journal schema 1 and paid/provider/non-replay boundaries
remain. Recovery does not replay browser actions or paid calls. The isolated
historical POC is unchanged. Version surfaces were generated by bump_version.py.
